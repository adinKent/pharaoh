# Maintain a versioned routing evaluation set

Routing changes will be evaluated against a versioned, anonymized case set covering multilingual requests, ambiguous entities, follow-ups, topic switches, fixed-command overlap, unavailable tools, stale data, and clarification cases. Capability, entity, freshness, tool, and safety outcomes will be measured before accepting routing changes, so improvements are not judged only by individual examples. The evaluation set must cover the complete declared capability taxonomy from the first implementation, even when internal delivery is staged.
