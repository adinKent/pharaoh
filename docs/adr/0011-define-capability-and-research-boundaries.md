# Define capability and research boundaries

Company analysis is about an issuer or company, while security analysis is about a specific financial security. Financial news covers recent events and announcements; web research covers cross-source background work or non-standard financial information. The Answer Generator must cite sources and effective times for recent and realtime answers and preserve the inputs behind calculations.

## Consequences

- A request may select both company and security analysis.
- Missing financial data must not automatically trigger unrestricted web research.
- Capability support requires an explicit route, entity requirement, planner behavior, tool contract, fallback, and evaluation coverage.
